Quick start

{{template "code-tabs" (list "curl" "Python" "MCP")}}
# 1. start (or attach to) a profile's browser
curl -X POST {{.Base}}/api/sessions \
  -H "Authorization: Bearer $PIER_TOKEN" \
  -d '{"profile": "google", "mode": "visual"}'
# → {"id": "…", "cdp_url": "{{wsURL .Base}}/cdp/google", …}

# 2. stuck? ask a human, send them the link, wait
curl -X POST {{.Base}}/api/sessions/$ID/handoff -H "Authorization: Bearer $PIER_TOKEN" \
  -d '{"reason": "sensitive_input", "detail": "Enter the 2FA code"}'
# → {"id": "…", "url": "{{.Base}}/h/…", "expires_at": "…"}
curl "{{.Base}}/api/handoffs/$HANDOFF?wait=900" -H "Authorization: Bearer $PIER_TOKEN"
# → {"status": "done", "note": "used a backup code"}

# 3. done: free the memory, keep the cookies
curl -X DELETE {{.Base}}/api/sessions/$ID -H "Authorization: Bearer $PIER_TOKEN"
# pip install playwright requests
import os, requests
from playwright.sync_api import sync_playwright

auth = {"Authorization": "Bearer " + os.environ["PIER_TOKEN"]}
s = requests.post("{{.Base}}/api/sessions", json={"profile": "google", "mode": "api"}, headers=auth).json()

with sync_playwright() as p:
    browser = p.chromium.connect_over_cdp(s["cdp_url"], headers=auth)
    # can't set headers? POST /api/sessions/{id}/cdp-ticket gives a
    # one-minute "cdp_url" that needs none
    page = browser.contexts[0].pages[0]
    page.goto("https://mail.google.com")

requests.delete("{{.Base}}/api/sessions/" + s["id"], headers=auth)
# Claude Code
claude mcp add --transport http browserpier {{.Base}}/mcp \
  --header "Authorization: Bearer $PIER_TOKEN"

# any MCP client that speaks streamable HTTP
{"mcpServers": {"browserpier": {
  "type": "http",
  "url": "{{.Base}}/mcp",
  "headers": {"Authorization": "Bearer ${PIER_TOKEN}"}

Endpoints

  • POST/api/sessionsStart or attach to a browser
  • DELETE/api/sessions/{id}Stop it, keep the profile
  • WS/cdp/{profile}API mode, token-checked
  • POST/api/sessions/{id}/cdp-ticketA CDP URL for clients that can't set headers
  • GET/api/sessions/{id}/screenshotVisual mode: see the screen
  • POST/api/sessions/{id}/clickVisual mode: click, and /type to type
  • GET/api/profiles/{name}/filesDownloaded files
  • POST/api/sessions/{id}/handoffOne-time link for a human
  • GET/api/handoffs/{id}Wait for the answer

MCP

Point Claude or any MCP client at /mcp with a token. Handoffs show up as a link the client opens for you, where it supports that.
