Browsers that stay logged in, for your AI agents.

Features

A browser pool built around logins, not page loads.

Most browser APIs give agents a fresh, anonymous browser. Agents that work in your accounts need the opposite: the same browser, still signed in, every time.

One persistent profile per service

Cookies, logins and local storage live on a volume that outlives every browser. Stop it, update it, restart the server: it's still signed in.

Idle browsers use no RAM

Browsers start when an agent asks and stop when idle. Near the memory limit, the longest-idle one makes room.

Plan for 1–2 GB per running browser. A 4–8 GB VPS fits 2–4.

MCP built in

Point Claude or any MCP client at /mcp. Handoffs appear as a native prompt where the client supports it.

Page text reaches the agent fenced as untrusted, with password fields redacted.
